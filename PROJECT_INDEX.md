# AIP Protocol — Project Index

## Purpose

AIP (AI Protocol) is an AI-agnostic task format.

Apps generate structured tasks.
Users run those tasks using their own AI systems.

## Core Rule

Applications do not require direct ownership of AI APIs.

Instead:

```text
App
↓
AIP Packet
↓
User AI
↓
Result
```

## Goals

- Model independence
- Provider independence
- Transparent task exchange
- Human-readable and machine-readable formats
