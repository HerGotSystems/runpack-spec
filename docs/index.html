PORTABLE TASK PACKET FORMAT

Make a pack.
Run it anywhere.

RunPack lets apps generate structured task packets that users run with their own AI. It is not an agent protocol, not a hosted AI service, and not a model vendor wrapper.

Apps make packets. Users paste or bridge them into ChatGPT, Claude, Gemini, local models, or future systems. Results can be pasted or imported back.

Legacy AIP compatible: existing aip_version fields remain valid during the v1.x transition.
EXAMPLE — RunPack task packet
{
  "runpack_version": "1.1",
  "legacy_aip_version": "1.1",
  "aip_version": "1.1",
  "packet_type": "runpack_task",
  "task": "document_summary",
  "input": { "text": "..." },
  "rules": ["plain_language", "no_preamble"],
  "output_format": "text"
}
