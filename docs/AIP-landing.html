TASK PACKETS FOR USER-RUN AI

Make a pack.
Run it anywhere.

RunPack is a portable task packet format for software that should not need to host AI inference. Apps generate packets. Users run them with their own AI. Results can be pasted or imported back.

It is not an agent protocol. It is not a hosted AI service. It is the missing handoff format between normal software and user-owned AI tools.

LEGACY AIP COMPATIBLE
RunPack — task packets for user-run AI.
AIP remains the v1.x compatibility layer.
WHY

Hosted AI is expensive glue.

Most small apps do not need to become AI companies. They need a clean way to ask the user's chosen AI to do one structured job and bring the result back.

01
No owner API burn
The developer is not paying for every public inference call.
02
No model lock-in
The same packet can be run through different AI systems.
03
Human-readable by default
A user can inspect the packet before running it.
HOW IT WORKS

App → packet → user AI → result.

01
App creates packet
The task, data, rules and expected output are bundled.
02
User runs it
Manual paste, browser bridge, local runner, future automation.
03
AI executes
The user's chosen AI does the intelligence work.
04
Result returns
Plain text or JSON result packet.
05
App imports
The app validates and uses the result.
